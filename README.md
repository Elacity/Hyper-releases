# Hyper Android releases

Signed Android APKs of Hyper (app id `os.elastos.hyper.social`). No source code lives here.

Each release has `hyper-android.apk` and `latest.json`. Before installing by hand, check that the APK's SHA-256 matches the `sha256` in `latest.json`. The in-app updater does this automatically and also requires the APK to be signed with the same key as the installed app.
